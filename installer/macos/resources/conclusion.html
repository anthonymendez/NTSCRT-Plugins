NTSCRT is installed

  • DaVinci Resolve: restart it, then Effects → OpenFX → Filters → NTSCRT.
  • Final Cut Pro: restart it, then Effects browser → NTSCRT. Keep /Applications/NTSCRT.app: the plug-in lives inside it.

Updating: run this installer again. It always installs the latest release.

Uninstalling: in Terminal, run
curl -fsSL https://raw.githubusercontent.com/anthonymendez/NTSCRT-Plugins/main/install.sh | sh -s -- --uninstall

The installer log is in /Library/Logs/NTSCRT/install.log (and /var/log/install.log).
